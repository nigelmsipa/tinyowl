# Tiny Owl — 3ABN Bible Q&A: NotebookLM Spirit of Prophecy Pass

**Context:** Each answer in this project is built in four layers:
1. **Scripture** — biblical foundation (we supply this)
2. **Spirit of Prophecy** — what Ellen White writes about the topic ← *your job*
3. **Historical / Scholarly** — historical background, scholarly context, reformation-era evidence ← *your job if sources cover it*
4. **Pastoral** — practical application (already captured in speaker transcripts)

**Instructions for each group:**
For each question below, provide **two things only**:
- What the Spirit of Prophecy sources (Ellen White's writings) say about this topic — cite inline by book title and chapter/section, e.g. *(The Great Controversy, "The Impending Conflict")* or *(Patriarchs and Prophets, "The Exodus")*.
- Any historical or scholarly context the sources provide — dates, figures, documents, historical events that illuminate the question.

Do **not** provide pastoral application — that comes from the speaker transcripts.
Do **not** restate basic scripture — we handle the biblical layer separately.
If a question is not addressed in the sources, skip it — do not speculate.
**Do not use footnote numbers or citation codes.** All citations must be inline prose references.
